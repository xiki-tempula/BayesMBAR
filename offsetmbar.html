Offset-Constrained Coupled BayesMBAR: Mathematical Formulation and Implementation#

Abstract#

We present OffsetMBAR, a coupled Bayesian MBAR (Multistate Bennett Acceptance Ratio) formulation that enforces a linear constraint across multiple MBAR systems. Each system corresponds to a standard MBAR problem with its own set of thermodynamic states, reduced energies, and sample counts, but we require that the free energy of a particular state in each system, shifted by a given scalar offset, is identical across systems. We formalize this constraint, derive a linear parameterization in terms of a lower-dimensional parameter vector, and prove that the implementation correctly enforces the constraint while preserving the MBAR likelihood. The resulting optimization problem is solved by Newton’s method or L-BFGS-B, and uncertainty is quantified by Hamiltonian Monte Carlo (HMC) sampling in the reduced parameter space.

1. Problem Setting#

Consider \(S\) MBAR systems, indexed by \(i = 0, \dots, S-1\). Each system has \(M\) thermodynamic states (assumed identical across systems):

  • Energies: For system \(i\), we have reduced potentials \(u_{i,k}(\mathbf{x})\) for states \(k = 0, \dots, M-1\), evaluated on a set of configurations (trajectories) with associated counts.

  • Counts: Let \(N_{i,k}\) be the number of configurations sampled from state \(k\) in system \(i\). The code represents these as arrays energies[i] and nums_conf[i].

We denote by

\[F_{i,k}\]

the dimensionless free energy (in units of \(kT\)) of state \(k\) in system \(i\). As in standard MBAR, these free energies are identifiable only up to an additive constant per system, so it is natural to work with free energy differences relative to a reference state.

2. Classical MBAR Parameterization#

For each system \(i\), we define free energy differences relative to state 0:

\[\Delta F_{i,k} \equiv F_{i,k+1} - F_{i,0}, \quad k = 0,\dots,M-2.\]

Thus each system has \(M-1\) independent parameters \(\Delta F_{i,0}, \dots, \Delta F_{i,M-2}\).

In vector form, for system \(i\) we define

\[\begin{split}\mathbf{d}_i = \begin{bmatrix} \Delta F_{i,0} \\ \Delta F_{i,1} \\ \vdots \\ \Delta F_{i,M-2} \end{bmatrix} \in \mathbb{R}^{M-1}.\end{split}\]

The associated state free energies can be reconstructed as

\[F_{i,0} = 0, \quad F_{i,k} = \Delta F_{i,k-1} \;\; \text{for } k=1,\dots, M-1.\]

i.e., the reference state 0 is fixed to zero, and all others are expressed as differences.

The standard MBAR log-likelihood (implemented via _compute_log_likelihood_of_dF) is a function

\[\log \mathcal{L}_i(\mathbf{d}_i; \text{energies}_i, \text{nums\_conf}_i),\]

and the joint log-likelihood across systems (without coupling) would be

\[\log \mathcal{L}(\{\mathbf{d}_i\}) = \sum_{i=0}^{S-1} \log \mathcal{L}_i(\mathbf{d}_i).\]

3. Offset Constraint Across Systems#

We wish to couple these systems in a specific way. For each system \(i\), we are given a scalar offset \(\mathrm{offset}_i \in \mathbb{R}\). We select a particular thermodynamic state in each system—specifically, the last MBAR state (index \(M-1\))—and enforce that its free energy plus the corresponding offset is identical across systems.

Let us denote this last MBAR state free energy as

\[F_{i, M-1}.\]

The constraint imposed in the code (see _compute_offset_projection) is:

\[F_{i,M-1} + \mathrm{offset}_i = c \quad \text{for all } i,\]

where \(c\) is a shared constant (a new global parameter).

Since \(F_{i,M-1} = \Delta F_{i,M-2}\) (because it is the last MBAR state above the reference 0), the constraint can be written equivalently as

\[\Delta F_{i,M-2} + \mathrm{offset}_i = c \quad \text{for all } i.\]

This defines a set of linear constraints tying together the last free-energy differences of each system.

4. Augmented State Space and Extra Offset State#

The implementation further introduces an extra offset state per system. For system \(i\), the final “offset” state is defined to have free energy equal to the common constant \(c\). Intuitively:

  • The last MBAR state (index \(M-1\)) remains the physical state whose free energy satisfies \(F_{i,M-1} + \mathrm{offset}_i = c\).

  • The offset state (index \(M\)) is a synthetic state whose free energy is exactly \(c\), common to all systems.

Thus each system ends up with \(M+1\) states when represented as F[i] in the code:

  • \(F_{i,0} = 0\) (reference),

  • \(F_{i,1}, \dots, F_{i,M-1}\) original MBAR states,

  • \(F_{i,M}\) additional offset state.

The constraint then becomes:

\[F_{i,M-1} + \mathrm{offset}_i = F_{i,M} = c, \quad \forall i.\]

This structure is reflected in _dF_to_state_F_with_offset, where for each system segment:

  • mbar_dF = dF[..., idx : idx + n - 1] holds the \(M-1\) MBAR free energy differences \(\Delta F_{i,0}, \dots, \Delta F_{i,M-2}\),

  • offset_value = dF[..., idx + n - 1] holds the extra offset state free energy, conceptually equal to \(c\).

The function reconstructs the full vector of free energies for system \(i\) as

\[\begin{split}\mathbf{F}_i = \begin{bmatrix} 0 \\ \mathbf{mbar\_dF}_i \\ \mathrm{offset\_value}_i \end{bmatrix} = \begin{bmatrix} 0 \\ \Delta F_{i,0} \\ \vdots \\ \Delta F_{i,M-2} \\ c \end{bmatrix} \in \mathbb{R}^{M+1}.\end{split}\]

5. Linear Parameterization via Projection Matrix#

The central mathematical device is the function _compute_offset_projection, which constructs a projection matrix \(Q\) and offset vector \(b\) such that

\[\mathbf{d} = Q \mathbf{x} + \mathbf{b},\]

where:

  • \(\mathbf{d}\) is the concatenated vector of length \(S \cdot M\), containing for each system:

    • The \(M-1\) MBAR free energy differences,

    • One additional scalar representing the offset state value.

  • \(\mathbf{x} \in \mathbb{R}^{n_{\text{indep}}}\) is a lower-dimensional vector of independent parameters:

    \[n_{\text{indep}} = S (M-2) + 1.\]

  • \(Q \in \mathbb{R}^{S M \times n_{\text{indep}}}\) is a full-rank linear map encoding both the unconstrained and constrained components.

  • \(\mathbf{b} \in \mathbb{R}^{S M}\) encodes the contribution from the known offsets \(\mathrm{offset}_i\).

5.1. Independent Parameters \(\mathbf{x}\)#

For each system \(i\), we treat the first \(M-2\) MBAR differences as unconstrained:

\[x_{(i,j)} = \Delta F_{i,j}, \quad j = 0, \dots, M-3.\]

This contributes \(S (M-2)\) free parameters. In addition, we introduce a global scalar:

\[x_{c} = c,\]

the shared constant appearing in the constraint.

Collecting all of these, we obtain \(\mathbf{x} \in \mathbb{R}^{S(M-2)+1}\).

5.2. Definition of \(Q\) and \(b\)#

For system \(i\) and its block within \(\mathbf{d}\), the code enforces:

  1. First \(M-2\) MBAR differences are identity:

    \[\Delta F_{i,j} = x_{(i,j)}, \quad j=0,\dots,M-3.\]

    In matrix form, this means that for corresponding indices,

    \[Q[\text{dF\_idx} + j, \text{x\_idx} + j] = 1,\quad b[\text{dF\_idx} + j] = 0.\]

  2. Last MBAR difference \(\Delta F_{i,M-2}\) satisfies the constraint:

    We know

    \[\Delta F_{i,M-2} + \mathrm{offset}_i = c \Rightarrow \Delta F_{i,M-2} = c - \mathrm{offset}_i.\]

    Hence this component is not free; it is given by

    \[\Delta F_{i,M-2} = x_c - \mathrm{offset}_i.\]

    In matrix/vector terms:

    \[Q[\text{dF\_idx} + M - 2, -1] = 1, \quad b[\text{dF\_idx} + M - 2] = -\mathrm{offset}_i.\]

  3. Offset state has free energy \(c\):

    The augmented offset state free energy is set to equal the same constant \(c\):

    \[F_{i,M} = c.\]

    As implemented, the offset state entry in \(\mathbf{d}\) is simply equal to \(c\):

    \[\mathrm{offset\_value}_i = x_c.\]

    Hence for the entry at dF_idx + M - 1:

    \[Q[\text{dF\_idx} + M - 1, -1] = 1, \quad b[\text{dF\_idx} + M - 1] = 0.\]

All other entries of \(Q\) and \(b\) are zero.

5.3. Proof that the Constraint is Enforced#

Let \(\mathbf{x}\) be any vector of independent parameters, and let \(\mathbf{d} = Q\mathbf{x} + \mathbf{b}\). Partition \(\mathbf{d}\) by system, and within each system, extract:

  • MBAR differences \(\Delta F_{i,0}, \dots, \Delta F_{i,M-2}\),

  • Offset state value \(F_{i,M}\).

From the construction:

  1. For \(j = 0, \dots, M-3\):

    \[\Delta F_{i,j} = x_{(i,j)}.\]

  2. For the last MBAR difference:

    \[\Delta F_{i,M-2} = x_c - \mathrm{offset}_i.\]

  3. For the offset state:

    \[F_{i,M} = x_c.\]

Reconstruct physical free energies as in _dF_to_state_F_with_offset:

  • \(F_{i,0} = 0\),

  • \(F_{i,k} = \Delta F_{i,k-1}\) for \(k = 1,\dots, M-1\),

  • \(F_{i,M} = x_c\).

Then the last MBAR state free energy is

\[F_{i,M-1} = \Delta F_{i,M-2} = x_c - \mathrm{offset}_i.\]

Therefore,

\[F_{i,M-1} + \mathrm{offset}_i = (x_c - \mathrm{offset}_i) + \mathrm{offset}_i = x_c,\]

which is independent of \(i\). This proves that for any \(\mathbf{x}\), the resulting free energies satisfy

\[F_{i,M-1} + \mathrm{offset}_i = c := x_c \quad \forall i,\]

and that the offset state \(F_{i,M} = c\) is also identical across systems.

Thus, the linear map \(\mathbf{x} \mapsto (Q\mathbf{x} + \mathbf{b}) \mapsto \{\mathbf{F}_i\}_i\) exactly enforces the specified offset constraint.

6. Likelihood and Loss Function#

Given \(\mathbf{x}\), the code computes:

  1. The full free energy-difference vector:

    \[\mathbf{d}_{\text{full}} = Q\mathbf{x} + \mathbf{b}.\]

  2. For each system \(i\), extracts the MBAR portion:

    \[\mathbf{d}_i = \mathbf{d}_{\text{full}}[i\text{-block}, \; :M-1].\]

    (i.e., the first \(M-1\) entries in that system’s block).

  3. Computes the MBAR log-likelihood for each system, as a function of \(\mathbf{d}_i\), energies, and counts, via _compute_log_likelihood_of_dF:

    \[\log \mathcal{L}_i(\mathbf{d}_i).\]

  4. Sums across systems:

    \[\log \mathcal{L}(\mathbf{x}) = \sum_{i=0}^{S-1} \log \mathcal{L}_i\big(\mathbf{d}_i(\mathbf{x})\big).\]

This is implemented in _compute_offset_log_likelihood.

Then _compute_offset_loss_likelihood defines the loss function as the (normalized) negative log-likelihood per configuration:

\[\mathcal{J}(\mathbf{x}) = - \frac{1}{N_{\text{tot}}} \log \mathcal{L}(\mathbf{x}),\]

where

\[N_{\text{tot}} = \sum_{i=0}^{S-1} \sum_{k=0}^{M-1} N_{i,k}\]

is the total number of samples across all systems. This normalization does not change the optimizer’s argmin, only the scale of the objective.

Key point: Because the map \(\mathbf{x} \mapsto \{\mathbf{d}_i\}\) is linear and injective (ignoring the usual additive reference freedom, which is fixed by setting \(F_{i,0}=0\)), optimizing \(\mathcal{J}(\mathbf{x})\) is equivalent to optimizing the MBAR log-likelihood in the constrained subspace.

7. Optimization and Mode Finding#

The constructor of OffsetMBAR proceeds as follows:

  1. Initializes \(\mathbf{x}_0 = 0\) (a zero vector of appropriate dimension).

  2. Chooses a method:

    • Newton: uses a JAX-jitted function computing value and gradient of \(\mathcal{J}\), and its Hessian, then calls fmin_newton to find a stationary point.

    • L-BFGS-B: uses SciPy’s optimize.minimize with objective and gradient computed via JAX (value_and_grad).

Let \(\mathbf{x}^*\) denote the optimizer found by either method. Then:

  • The mode of the constrained likelihood in the \(\mathbf{x}\)-space is \(\mathbf{x}^*\).

  • The corresponding mode in the \(\mathbf{d}\)-space is

    \[\mathbf{d}^* = Q\mathbf{x}^* + \mathbf{b}.\]

  • The state free energies per system are computed via _dF_to_state_F_with_offset:

    \[\{\mathbf{F}_i^*\} = \text{\_dF\_to\_state\_F\_with\_offset}(\mathbf{d}^*, \text{nums\_state}).\]

These are stored as:

  • self._dF_mode_ll = \(\mathbf{d}^*\),

  • self._state_F_mode_ll = \(\{\mathbf{F}_i^*\}\).

The public property F_mode converts these JAX arrays to NumPy on CPU.

By construction (Section 5.3), \(\{\mathbf{F}_i^*\}\) exactly satisfy

\[F^*_{i,M-1} + \mathrm{offset}_i = c^*\]

for all \(i\), where \(c^* = x_c^*\).

8. Posterior Sampling via HMC#

If sample_size > 0, the implementation samples from the posterior (or likelihood) in \(\mathbf{x}\)-space around the mode:

  1. Defines

    \[\log p(\mathbf{x}) := \log \mathcal{L}(\mathbf{x}) = \text{\_compute\_offset\_log\_likelihood}(\mathbf{x}, Q, b, \text{energies}, \text{nums\_conf}).\]

    (Strictly speaking, this is the log-likelihood; one can interpret it as log-posterior if combined with a flat prior.)

  2. Uses _sample_from_logdensity (an HMC-based sampler from bayesmbar.py) with:

    • Initial position \(\mathbf{x}_0 = \mathbf{x}^*\),

    • Log-density function \(\log p\),

    • Warmup steps and number of samples specified.

This yields a set of samples \(\{\mathbf{x}^{(s)}\}_{s=1}^S\) from an approximation to the posterior over \(\mathbf{x}\). Each is mapped to:

  • Free energy differences:

    \[\mathbf{d}^{(s)} = Q\mathbf{x}^{(s)} + \mathbf{b}.\]

  • System-wise free energies:

    \[\{\mathbf{F}_i^{(s)}\}.\]

The properties:

  • F_samples gives \(\{\mathbf{F}_i^{(s)}\}\),

  • F_mean gives their sample mean,

  • DeltaF_mode, DeltaF_mean, and DeltaF_std report derived statistics of pairwise free-energy differences within each system.

Each sampled \(\mathbf{F}_i^{(s)}\) inherits the linear constraint (Section 5.3), so the offset condition holds for all samples, not only for the mode.

9. Summary of Mathematical Soundness of the Implementation#

  • The constraint \(F_{i,M-1} + \mathrm{offset}_i = c\) is encoded as a linear condition in the free energy differences \(\mathbf{d}\).

  • A full-rank projection \((Q,b)\) is constructed such that any \(\mathbf{x}\) yields a \(\mathbf{d} = Q\mathbf{x} + \mathbf{b}\) satisfying the constraint exactly.

  • The MBAR likelihood is evaluated only on the physical MBAR states (excluding the synthetic offset state), ensuring that the constraint does not artificially alter the likelihood contributions.

  • Optimization in \(\mathbf{x}\)-space is equivalent to maximizing the MBAR likelihood in the constrained subspace of \(\mathbf{d}\)-space.

  • Sampling in \(\mathbf{x}\)-space, using the same projection, produces uncertainty estimates that are consistent with both the MBAR likelihood and the offset constraint.

Taken together, these components form a coherent and mathematically consistent realization of the offset-constrained coupled BayesMBAR model.
